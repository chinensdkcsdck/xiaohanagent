# 医疗导诊与预约智能体系统｜简历写法（AI核心 + 高并发亮点）

## 1. 项目名称
医疗导诊与预约智能体系统（LLM + RAG + Skills + Tool Calling）

## 2. 项目描述（2-3行）
基于 LangChain4j 构建医疗智能体后端，设计 `Skills` 决策层与 `@Tool` 执行层，实现导诊、挂号、改约、检查、报告解读等场景的“理解-决策-执行”闭环；并通过可观测与并发治理保障线上稳定性。

## 3. 技术栈
1. Java 17、Spring Boot 3.2.6、Spring WebFlux（SSE）
2. LangChain4j 1.0.0-beta3、DashScope Qwen、Tool Calling
3. RAG：Embedding 检索 + Pinecone（可降级 InMemory）
4. MySQL、MongoDB、MyBatis-Plus、Flyway
5. Redis / MySQL 分布式锁、RabbitMQ（重试/退避/DLQ）
6. Micrometer + Actuator + TraceId

## 4. 个人职责（主次明确）
1. 主导设计 `Skills + @Tool` 智能体架构，实现意图路由、场景化执行与能力解耦。
2. 实现预约场景 `ASK_SLOT` 追问机制，缺少科室/日期/时段时自动补槽位。
3. 建设 RAG + Tool + Skill 指标体系，支持 AI 质量评估与持续调优。
4. 打通 AI 决策到交易执行链路，落地可执行医疗助手。
5. 作为工程亮点补齐高并发治理：分布式锁、事务改约、幂等消费、DLQ 告警闭环。

## 5. 核心亮点（简历可直接贴）
1. 以 `Skills` 作为 AI 大脑、`@Tool` 作为执行手脚，完成医疗智能体闭环。
2. 通过 `ASK_SLOT` 机制提升预约类请求参数完整率和工具调用成功率。
3. 建立可观测 AI 工程体系（`app.rag.*`、`app.chat.*`、`app.skill.*`），支持数据化调优。
4. 引入高并发治理作为工程加分项：分布式锁 + 事务原子化 + 幂等消费 + DLQ。
